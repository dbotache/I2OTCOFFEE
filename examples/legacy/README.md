# Legacy standalone examples

Original webcam, face-detection, and drowsiness scripts and the alarm sound are preserved here. They are not maintained entry points and may require extra dependencies (`imutils`, SciPy, and `playsound`), local paths, and GUI/audio support. Model defaults in these scripts refer to their original working directory; the preserved model is now in `../../models/`.

Use `i2otcoffee` for the maintained camera demo. The provenance and redistribution terms of these historical snippets and `alarm.WAV` are not recorded in the original repository and require review before redistribution.

The historical material described above is excluded from the project's Apache-2.0 grant. This explanatory README is covered. See [licensing scope](../../docs/LICENSING.md).
